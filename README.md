# SuperFly Internal Dashboard

This repository contains the standalone SuperFly internal operations dashboard and its logo asset.

The dashboard is a static site designed for GitHub Pages. Open `index.html` locally for review, or use the published Pages URL once deployment is enabled.

## Contents

| Path | Purpose |
|---|---|
| `index.html` | Internal operations dashboard with artist roster, budget, event schedule, and progress tracker. |
| `assets/superfly-logo.jpg` | SuperFly logo used in the dashboard header. |

## Confidentiality

This dashboard contains internal operations information. The repository is public at the request of the repository owner to enable GitHub Pages hosting. Do not add credentials, private documents, or additional confidential data.
